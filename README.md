This repository compiles machine learning tasks, data wrangling pipelines, and statistical modeling scripts completed during my **Prodify Machine Learning Internship**.

---

## 📂 Core Work Scope
* **Data Processing**: Cleaning outliers, parsing dates, encoding categories, and normalization.
* **Classification Modeling**: Building classifiers to catalog dataset categories.
* **Regression Metrics**: Estimating numerical outputs using custom parameters and evaluating predictions with RMSE and MAE.
* **Feature Selection**: Identifying correlation indices and selecting features.

## ⚙️ Run Locally


